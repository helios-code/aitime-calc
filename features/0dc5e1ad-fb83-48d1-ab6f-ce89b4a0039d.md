## 2. Root cause & decisions

# niwa-decision — Share button: copy permalink on Compare/Timeline (task 0dc5e1ad)

ROOT_CAUSE: Permalinks (a473ce0a) + OG images exist, but Compare's only affordance was a
plain "Copy link" button with no feedback, and Timeline had none — users had to copy the
address bar. Closes today's social loop.

DECISION:

- New `lib/share.ts` `sharePermalink(url)` — pure, testable, dependency-light: prefers
  `navigator.share` (mobile/secure context), falls back to `copyToClipboard`. Returns
  `'shared' | 'copied' | 'failed'`. Never throws; a cancelled native sheet (AbortError)
  is treated as handled ('shared') — no silent copy behind the user's back.
- New `components/ShareLinkButton.tsx` — thin UI over `sharePermalink`: localized label
  (`t.share.copyLink`), inline "Copied ✓" (`t.share.copied`) feedback that auto-clears,
  and a `role=status` failure message (`t.share.failed`). Reused on both pages.
- New `urlState.appendLang(search, locale)` — appends `?lang` to a state search string so
  a shared permalink opens in the sharer's language. English is default and left implicit
  (same rule as encode* dropping default model/as_of), keeping URLs clean. Pure, so the
  "share URL === urlState encoding (+lang)" contract is unit-tested without a DOM.
- Compare: swapped its inline copy button for `<ShareLinkButton>` and wrapped shareUrl
  with `appendLang(…, LOCALE)` (it previously dropped lang). Timeline: added a share-card
  (styles already global in App.css) with the button + a new `t.timeline.shareLabel`.

SCOPE GUARDS: `/embed` untouched; the Home `ShareCard` (copy-embed) untouched.

ALTERNATIVES REJECTED:
- Reusing `ShareCard` directly — it is result-shaped (needs a CalcResult, builds share
  TEXT + embed). A permalink-only button is a cleaner primitive for these two pages.
- A component (RTL) test — repo has no @testing-library/react; convention is pure lib
  tests. Logic lives in `share.ts` / `appendLang` and is covered there instead.

VERIFICATION: `npm run test` 125 passed (17 files); `npm run build` (tsc -b + vite) green;
`oxlint src` exit 0 (only 2 pre-existing warnings in untouched files).
