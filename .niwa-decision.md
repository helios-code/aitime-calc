# .niwa-decision — task 1f2e786c (i18n: localize humanizer + FR string gaps F1/F2/F3)

ROOT_CAUSE: `computeCalc` (web `atem.ts`) and the live API (`server.ts`) bake human-readable strings
in ENGLISH — `comparison_line` ("≈ N classic software generations"), `human_equiv_human`
("28 years 3 months"), `elapsed.human` ("1 yr 9 mo"). The web UI rendered those baked English fields
verbatim, so FR pages showed mixed-language text (visual-QA F1/F2). The timeline Y-axis hard-coded a
"y" suffix (F3).

DECISION:
- Single source of truth: new `web/src/lib/humanize.ts` — `humanizeDuration(years, months, locale, style)`
  (EN short "7 yr 6 mo" / long "28 years 3 months"; FR "7 ans 6 mois", an→ans at >1, mois invariant),
  plus `elapsedYearsMonths` and `splitYears`. `atem.ts` now uses it for its EN canonical strings, so the
  API/JSON contract and non-UI consumers are unchanged (fields kept, still English).
- Localize in the PRESENTATION layer, not the compute/contract layer: components (ResultHero, Compare,
  ShareCard) re-derive locale-aware durations from the NUMERIC fields (`input.release_date`/`as_of`,
  `human_equiv_years`, `ai_doublings`) via the humanizer + new i18n keys `result.comparisonLine` and
  `timeline.yTickSuffix`. This works identically on the live and mock paths WITHOUT an API round-trip or
  a contract change (which would have collided with dev's concurrent /api/og work, task b362be17).
- F3 suffix choice: FR `yTickSuffix = 'a'` (annum) — a compact single-letter unit matching EN 'y' on the
  terse log axis; spelled "ans" would crowd the narrow left gutter.
- Coordination: humanize.ts is the canonical humanizer; it carries a DUPLICATION POINTER to
  `api/src/server.ts` (`yearsToHuman` + `comparison_line`) / `/api/og`, which mirror the EN forms
  server-side. Pointer comments left both ways. If EN wording changes, mirror it there.
- Out of scope (confirmed by cto): tool descriptions stay EN — API source data, product call pending.

TESTS: `humanize.test.ts` (EN+FR both styles, pluralization, split/carry, calendar elapsed);
`ShareCard.test.ts` asserts FR share text is fully French with zero EN unit/phrase fragments (F1/F2).
Build green; 134 web tests pass. Visual-confirmed FR home/compare/timeline render localized (F1/F2/F3
closed), tool description the only remaining EN (by design).
