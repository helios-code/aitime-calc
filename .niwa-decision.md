# niwa-decision — Localize OG share images (?lang=fr) (task b362be17)

ROOT_CAUSE: i18n (3b8fb68c) localized the UI and share permalinks (862f220f) carry
`?lang=fr`, but `/api/og` rendered English-only cards — so a French permalink unfurled a
mismatched English social card. Two gaps: (1) the API card copy was hardcoded English;
(2) the embedded OG font was a Basic-Latin-only subset (9516cff), so FR accents would
render blank even once the copy was localized.

DECISION:

**API (`api/src/server.ts`).**
- Add `lang?: string` to `OgQuery`; `resolveOgLocale` maps `fr`→fr, everything else→`en`
  (mirrors web `resolveLocale`'s default; invalid lang is a safe EN fallback).
- `OG_STRINGS` (en/fr) holds the few card labels — eyebrow ("release date" /
  "date de sortie"), hero prefix ("By" / "Le"), model label ("base model" /
  "modèle base", "accelerating model" / "modèle accéléré"). Duplicated from
  `web/src/lib/i18n.ts` with a comment pointing there as the source of truth (og renders
  api-side, can't import web).
- `formatDateLabel(d, locale)` uses `Intl` `en-US`/`fr-FR`; `humanEquivLabel(years, locale)`
  is a locale-aware "N years M months" / "N ans M mois". `atem.yearsToHuman` stays English
  — it feeds the JSON API, not the card.
- Tool/vendor names are dataset data — never localized.

**Font (`api/assets/fonts/*-subset.ttf`).** Verified with fontTools: the committed subset
covered 0 of {é è à ç û « » œ}. Regenerated both Regular+Bold from the full DejaVu Sans
(matplotlib's copy) via `pyftsubset` with unicodes
`U+0020-007E,U+2013,U+2014,U+2018-201F,U+2026,U+00A0-00FF,U+0152,U+0153`. Result: 204
glyphs (was 106), all FR accents + guillemets present, and SMALLER (23KB/20KB vs 45KB/42KB)
thanks to `--no-hinting --desubroutinize`. DejaVu licence unchanged (LICENSE.txt).

**Web (`web/middleware.ts`).** `buildOgImageUrl` forwards `lang=fr` to the `/api/og` URL so
FR pages emit a FR `og:image`. Only `fr` is forwarded — `en` is the API default, so EN
image URLs stay lang-free (no regression to existing tags). Matches the web `LANG_PARAM`
contract.

TESTS:
- api `og.test.ts`: FR tool-mode + date-mode labels, accented month ("août"), accelerating
  label, invalid-lang→EN fallback, **EN-unchanged-when-lang-absent regression**, and a
  pixel render test proving FR accented glyphs paint (>500 non-bg) and differ from the EN
  card (guards the subset).
- web `middleware.test.ts`: `lang=fr` forwarded; `lang=en`/unknown not forwarded.

VERIFICATION: api 81 passed (7 files), web 127 passed (17 files); `api` + `web` builds
green (tsc clean); `scripts/gate-check.sh` → api PASS / web PASS (exit 0); `oxlint` clean
on touched files (2 pre-existing warnings in untouched components).
