# niwa-decision — Shareable permalinks (task 3588674e)

ROOT_CAUSE: /compare decoded ?tool=&vs= on cold load and showed a copyable share
link, but never wrote state to the address bar and had no Back/Forward support;
/timeline had no URL state at all. So a link only reproduced a view if the user
clicked "Copy link" — the address bar itself was not a permalink, and browser
history didn't track view changes.

DECISION: Add a small pure lib `web/src/lib/urlState.ts` (encode/decode for both
views + a guarded `syncSearch` history wrapper), reusing the existing
`urlParams` validators so the tool-id/date contract stays single-sourced. Wire it
into Compare.tsx and TimelinePage.tsx. No API changes; no new deps.

- Compare: selected tools (?tool, ?vs) + optional ?as_of + ?model round-trip.
  Address bar updates live; direct load restores identical state.
- Timeline: gains a Base/Accelerating ModelToggle whose choice is the shareable
  param (?model). `buildTimelinePoints` took a new optional `model` arg
  (defaults 'base' — existing callers/tests unchanged).

HISTORY — push vs replace: user-initiated changes use **pushState**, so each
distinct view becomes a history entry and Back/Forward walks the sequence a user
actually explored (the product goal — permalinks as a social/back-navigation
loop). A `popstate` listener re-decodes the restored URL back into state. The
push effect **skips when the freshly-encoded search already equals
window.location.search** — this is exactly the post-popstate case (we wrote that
URL) and any no-op change, which prevents the classic popstate→setState→push echo
that would strand Back. No replaceState needed; the initial URL is left as-is.

GRACEFUL DEGRADATION: unknown/invalid ids, dates, and model values decode to
defaults and never throw (isPlausibleToolId / isValidDateStr from urlParams;
model !== 'accelerating' → 'base'). Base model and absent as_of are kept OUT of
the URL to keep links clean. Existing routes and /embed are untouched
(parseInitialState / parseCompareState in urlParams left intact for the home and
embed contracts).

TESTS: web/src/lib/urlState.test.ts covers encode/decode round-trips, alias
resolution, default-omission, and invalid-input degradation for both views.
