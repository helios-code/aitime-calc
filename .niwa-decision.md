# niwa-decision — Remove dead parseCompareState (task 666c4a07)

ROOT_CAUSE: The permalinks merge (3588674e / a473ce0a) introduced decodeCompare in
urlState.ts and pointed Compare.tsx at it, leaving parseCompareState + its
CompareState interface in urlParams.ts referenced only by their own test — dead app
code, and a second compare-URL decoder that could drift from decodeCompare.

DECISION: Pure deletion, no behavior change.
- Removed `CompareState` interface + `parseCompareState` from web/src/lib/urlParams.ts.
- Removed the `describe('parseCompareState')` block and the symbol from the import in
  web/src/lib/urlParams.test.ts. All other urlParams tests untouched.
- Verified no production code referenced the symbols (grep clean). Remaining imports
  in urlParams.ts (CalcModel, resolveToolId, isPlausibleToolId) still used by
  parseInitialState. decodeCompare in urlState.ts is now the single compare-URL decoder.
